# Baken-KING v1.00 最終総合テスト（2026-11-05）

## 目的・判定基準
現行本番コミット `b15f3f1c35a0da9e21470b5e482a38cedef3d763` を基準として、既存機能の総合回帰テストを GitHub Actions の UI smoke / Validate JavaScript で再実行する。機能追加・バージョン変更・本番データ操作は行わない。

## 自動テスト対象
- **出馬表・予想**：開催日切替、期限切れ非表示、未取得待機表示から新規取得時の自動復帰、レース選択
- **購入・保存**：購入と端末ストレージ、リロード後の残存、モード分離
- **精算**：正式払戻と返還、未確定、二重精算防止、履歴、バックアップ・復元
- **ログイン・友達**：認証とOTP、友達管理表示、画面内「戻る」、申請と承認、9項目比較と同期、公開範囲
- **自動連携**：購入レースの監視登録、出馬表フィード、検証済み結果フィード、精算待ち通知イベント、プッシュ購読
- **権限と安全性**：API認証、不正アクセス拒否、DB更新範囲、プライベートバックアップ

## 実環境の別判定
- Vercel 本番デプロイが `READY` であるか確認する。
- ログイン済みiPhoneにおけるログイン・友達管理・出馬表待機表示はユーザー操作による別確認。
- **未検証のまま成功扱いしない**：JRA実開催の出馬表取得、GitHub監視ワークフローによるアカウント監視対象の実取り込み、二回一致する公式結果の配信、実際の馬券が精算待ちとなること、iPhoneへの実プッシュ配信。
- `MONITOR_REGISTRATION_MODE=accounts` の実運用有効化とGitHub Actionsの監視実行ログ・配信結果は別途確認が必要。緑色の監視ジョブだけでは対象レースの取得成功を意味しない。

## 安全方針
本テストのために馬券・残高・精算履歴・実DBレコード・認証設定を変更しない。テストは CI の独立実行環境に限定する。v1.00 を維持する。
